# List representation of a list environment

List representation of a list environment

## Usage

``` r
# S3 method for class 'listenv'
as.list(x, all.names = TRUE, sorted = FALSE, ...)
```

## Arguments

- x:

  A list environment.

- all.names:

  If `TRUE`, element names starting with a period are included,
  otherwise not.

- sorted:

  If `TRUE`, elements are ordered by their names before being compared,
  otherwise not.

- ...:

  Not used.

## Value

A list.
